# Assay engineering blog

First-person engineering notes from building `assay-action`.

These posts are allowed to be opinionated, narrative, and specific. They are
not reference pages, ADRs, or product docs.

## Posts

- [We Almost Shipped a Baseline Diff That Lied](we-almost-shipped-a-baseline-diff-that-lied.md)

## Blog contract

Every post in this directory should:

1. Start from a concrete engineering decision or failure mode.
2. Explain the tradeoff in plain language.
3. Name what changed because of the lesson.
4. Avoid turning a story into a generic product pitch.

If a page is neutral, templated, and task-shaped, it belongs in
[`docs/use-cases/`](../use-cases/README.md). If it freezes an implementation
decision, it belongs in [`docs/adrs/`](../adrs/).
